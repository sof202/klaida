demo error reference

E1001: Input arrays have different lengths

Cause

x and y came from different sources, or only one of them was filtered.

Fix

Check that len(x) == len(y) before calling fit().

Details

Raised at the start of fit(), before any work is done.

fit([1, 2, 3], [1, 2])   # raises E1001

It is most often caused by filtering x but not y.
